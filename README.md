# 로또 6/45 번호 추첨기

휴대폰 홈 화면에 설치해서 쓰는 로또 6/45 웹앱이에요.

- 1회부터 최신 회차까지 1등·2등 당첨번호의 출현 횟수로 번호마다 확률을 매겨 뽑아요 (많이 나온 번호 / 적게 나온 번호 / 균등).
- 고정수·제외수를 지정할 수 있어요.
- 카메라로 용지 QR을 비추면 게임마다 몇 등인지 바로 알려줘요. 추첨 전 용지는 저장해 두었다가 추첨 후 자동으로 확인해요.
- 내 번호의 당첨 여부, 역대 전 회차 대조, 확률 검사를 해 줘요.
- 한 번 열면 인터넷이 없어도 열려요.

## 설치

안드로이드 크롬에서 사이트를 열고 **앱 설치** 버튼(또는 메뉴 ⋮ → 앱 설치 / 홈 화면에 추가)을 누르세요.
아이폰은 사파리에서 공유 버튼 → **홈 화면에 추가**를 누르세요.

## 당첨번호 자동 업데이트

GitHub Actions(`.github/workflows/update-draws.yml`)가 매주 토요일 밤과 일요일에 `scripts/update_draws.py`를 실행해요.
동행복권 공식 API를 먼저 시도하고, 안 되면 공개 미러 여러 곳에서 번호가 두 곳 이상 일치할 때만 `data/draws.json`에 추가해요.
Actions 탭에서 **Run workflow**를 누르면 바로 실행할 수도 있어요.

추첨은 매번 독립이라 과거 출현 횟수가 다음 결과에 영향을 주지는 않아요. 어떤 방식이든 1등 확률은 1/8,145,060이에요.

QR 해독: [jsQR](https://github.com/cozmo/jsQR) 1.4.0 (Apache-2.0, `vendor/`).
